# Golden Fork Grill

Golden Fork Grill is a responsive restaurant menu website created using HTML and CSS. This project demonstrates front-end web development skills with a focus on modern CSS styling, responsive layouts, and navigation.

## Project Overview

The website allows users to navigate through different restaurant menu categories, including appetizers, entrees, desserts, and beverages. Each page uses consistent styling to create a clean and user-friendly design.

## Features

- Responsive website design
- Multi-page navigation
- Appetizers and entrees menu
- Desserts and beverages menu
- CSS Grid layout
- Flexbox navigation
- Menu cards
- Hover effects
- CSS transitions and transforms
- Gradient backgrounds
- Box shadows and rounded corners
- Google Fonts
- Mobile-friendly media queries

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Google Fonts

## CSS Skills Demonstrated

This project demonstrates several CSS techniques, including:

- Responsive layouts
- CSS Grid
- Flexbox
- Pseudo-classes
- Hover effects
- Transitions
- Transforms
- Gradients
- Box shadows
- Typography
- Spacing
- Media queries

The menu cards use CSS Grid to organize content on larger screens. Media queries change the layout on tablets and mobile devices to make the website easier to use on different screen sizes.

## Pages

### Home

The home page introduces Golden Fork Grill and displays popular menu items. It also provides navigation to the restaurant's menu pages.

### Appetizers & Entrees

This page displays appetizers and main entrees using responsive menu cards with food descriptions and prices.

### Desserts & Beverages

This page displays dessert and beverage options using the same responsive card layout and styling.

## Responsive Design

The website is designed to work on desktop, tablet, and mobile devices. CSS media queries adjust the navigation, text, and menu grid depending on the size of the screen.

## Purpose

The purpose of this project is to practice and demonstrate HTML and CSS skills while creating a complete responsive restaurant website.
